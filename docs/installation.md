# Instalação — moodle-local_tinytoolbar

## Requisitos

- **Moodle**: 4.5 ou superior (`2024042200`+)
- **PHP**: 8.1, 8.2 ou 8.3
- Editor TinyMCE ativado no Moodle.

---

## Métodos de Instalação

### Via ZIP da Release

1. Baixe o ZIP da versão mais recente nas Releases do GitHub.
2. Acesse: **Administração do site → Plug-ins → Instalar plug-ins**.
3. Envie o ZIP e prossiga com o assistente de instalação.

### Via Git Clone

```bash
cd /caminho/do/moodle/local
git clone https://github.com/moodle-by-kelsoncm/moodle-local_tinytoolbar.git tinytoolbar
```

Após clonar, acesse **Administração do site → Notificações** para concluir a atualização.
