# Guia de Uso — moodle-local_tinytoolbar

## Recursos Avançados

- **Exportação e Importação de Layouts**: Permite exportar as configurações do TinyMCE em JSON para migração entre instâncias Moodle (dev → staging → prod).
- **Validação de JSON**: Garante que apenas botões e plugins TinyMCE válidos sejam salvos.
